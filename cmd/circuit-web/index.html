Routing and details
Unchecked (default) preserves the legacy method, which adds random jitter to route costs. Checked uses fixed move and turn costs; randomization still affects exploration order and ties.
Preferred placement links are always tried first. Randomized shuffles fallback links; ranked favors same-cluster links, then shorter axial distances. Ties remain randomized.
Randomness
With a fixed seed, changing settings keeps the same random layout where the settings permit it. Turn off the checkbox to use a fresh seed for each update.
